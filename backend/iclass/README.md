data: This only contains tables and some enums/domains that are needed for those tables. No functions, triggers, RLS, views. The code for the data layer is written through migrations. So the extension upgrade files are written by hand here - treating the migration code as "the source of truth". I also have some dump-scripts to dump the whole layer into some CREATE TABLE ... statements, to make it easier to see at first glance how the schema looks like - even when reviewing PRs. Those dumps are checked in git, too.
